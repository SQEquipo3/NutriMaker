## 🌱 ¿Qué es NutriMaker?

**NutriMaker** es una aplicación de escritorio desarrollada en **Java y JavaFX** que facilita la creación, administración y personalización de planes alimenticios. Está orientada a organizar la información de pacientes y sus dietas, reuniendo en un mismo lugar las herramientas necesarias para la planificación nutricional.

Su propósito es simplificar tareas repetitivas y ofrecer una experiencia clara para gestionar comidas, horarios y datos nutricionales.

## 🎯 Nuestro objetivo

Desarrollar una herramienta práctica que permita **optimizar la planificación nutricional**, mejorar la organización de los datos de los pacientes y facilitar la adaptación de dietas a distintas necesidades.

## ✨ Funcionalidades principales

- 🥗 **Generación de dietas:** elaboración de planes alimenticios a partir de parámetros nutricionales.
- 👤 **Gestión de pacientes:** registro y consulta de información relevante para su seguimiento.
- ✏️ **Edición de dietas:** personalización de planes alimenticios existentes.
- 📋 **Clonación de dietas:** reutilización de planes para otros pacientes sin alterar el original.
- 🍽️ **Organización de comidas:** distribución de alimentos y horarios dentro de cada plan.
- 📊 **Información nutricional:** seguimiento de calorías, proteínas, carbohidratos, grasas y otros nutrientes.
- 📄 **Exportación a PDF:** generación de documentos para consultar y compartir planes.
- 💾 **Almacenamiento persistente:** gestión de datos mediante MySQL.

## 🧩 ¿Qué ofrece NutriMaker?

NutriMaker integra en una sola aplicación la **gestión de usuarios**, el **registro de pacientes** y la **administración de dietas**. De esta manera, los planes pueden consultarse, ajustarse y reutilizarse de forma organizada.
